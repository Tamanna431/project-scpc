              SCIC API Dashboard

              Welcome to the production-ready REST API console. This is an interactive portal designed to view documentation and perform live REST requests against the backend server.

              Quick Start Checklist

              1. Register & Login

              Go to the Authentication section. Register a user and run the login endpoint to fetch a JWT token.

              2. Set Token

              Copy the returned token and paste it into the Bearer Token (JWT) field in the top bar. This will authorize all subsequent requests.

              3. Explore CRUD

              Explore Users, Categories, Products, Reviews, and Orders. You can run Create, Read, Update, and Soft Delete actions directly.

              Technical Stack Specifications

              Backend Engine Express.js (TypeScript)
              Database Layer PostgreSQL + Prisma ORM
              Authentication JWT (jsonwebtoken) & Hashed passwords (bcrypt)
              Relational Models User, Category, Product, Review, Order
